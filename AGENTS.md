# Agent Prompt

<!-- BEGIN:project-description -->

## Meme Style Transfer

This project takes a set of example images and a prompt and tries to generate a meme with the content in the prompt and the style of the example images.
Supports Google and OpenAI vision-text models currently.

<!-- END:project-description -->
